## Se mantiene como mejora futura

- **DEC-01 · [B-ADV-0038](../../plan/bugs/B-ADV-0038-evidencia-posix-real-para-cierre-de-arneses.md)** conserva `status: backlog` y sigue sin versión. Aunque ambas incidencias pasan por `orquestar.py`, B-ADV-0038 comprueba cómo termina el grupo de procesos durante una invocación. B-ADV-0044 evalúa el avance entre invocaciones. Ejecutar la prueba POSIX pendiente no es un prerrequisito para distinguir un diagnóstico repetido de un avance real.
